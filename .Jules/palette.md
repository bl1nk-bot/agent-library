## 2024-05-14 - Interactive element accessibility in custom kids settings
**Learning:** Custom toggle buttons using emojis (e.g., `<button>🔊 On</button>`) cause redundant screen reader announcements if emojis aren't hidden with `aria-hidden="true"`, and standard interactive elements built manually often miss basic accessibility bindings like `aria-pressed` for toggles and `aria-label` for sliders (`<input type="range">`), breaking screen reader usability.
**Action:** When auditing custom UI elements (like pixel art toggles or range sliders) in distinct layout sections (e.g., `kids/layout`), explicitly add `aria-pressed` for toggles, `aria-label` for implicitly labeled inputs, `aria-hidden` to decorative icons/emojis, and explicit `focus-visible` ring styling to maintain accessibility parity.
