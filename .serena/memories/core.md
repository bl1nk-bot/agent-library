# Core Architecture

Social platform for AI prompts and agent tooling.

## Key Subsystems
- `src/app`: Next.js 16 App Router (pages, API routes, admin).
- `src/components`: UI components (shadcn/ui base, prompts, kids UI).
- `src/lib`: Core services, DB client, auth, i18n, plugins.
- `messages/`: next-intl JSON dictionary files for 18+ languages.
